Centers Explanation Program

Offline report builder — select centers, channel types/circuits, and members, then download a Word report.

How to use

Turn on centers and/or channel type & circuit toggles, plus members. Center sections include only gates in the selected center(s). Channel type and circuit sections stand on their own (they are not filtered by center choice) and list each selected member’s completed channels in that category. Throat selections include each gate’s voice. The .docx keeps the approved condensed style (title header, centered Page X of Y footer, H1/H2/H3). Length expands with added type/circuit selections.

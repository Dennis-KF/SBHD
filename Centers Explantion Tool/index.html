How to use

Turn on one or more centers and members. The Report includes only gates that sit in the selected center(s). Throat selections include each gate’s voice. The downloaded .docx matches the condensed sample structure (title header, centered Page X of Y footer, headings, ≤6 pages when copied selections stay focused).

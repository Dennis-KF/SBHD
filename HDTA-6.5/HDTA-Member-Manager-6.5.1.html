HDTA Member Manager 6.5.1

Private tool for the HDTA-6.5 folder on sbhd.net. This page stays on your computer — do not upload it to GitHub.

The public page at https://sbhd.net/HDTA-6.5/ reads its official members from members.js. After you save a new list here, upload that file into the HDTA-6.5 folder (same place as index.html), replacing the previous members.js. Leave Transit-6 alone.

Or drag a chart file here to add someone. You can also drop a saved members.js to open it.

The original six members are loaded. You can add, remove, rename, or reorder, then save members.js.

How to use this

  1. This file works offline. Double-click it in Chrome, Edge, or Firefox on your computer.
  2. Add people with Browse for a chart file (or drag a .json, .txt, or .docx bodygraph onto the page). A PNG image is not enough — the chart data itself is required.
  3. Edit the first name if needed. Tap the small female/male tag only if it is wrong. A dash means the gender is unknown; the public page will then use the name only, with no pronouns.
  4. Use Up, Down, and Remove to arrange the official list. Remove works on the original six too, if you want that.
  5. Press Save members.js. Upload the downloaded file into the GitHub folder HDTA-6.5, replacing the previous members.js.
  6. Wait a few minutes, then refresh https://sbhd.net/HDTA-6.5/index.html. The official quick-load buttons will match this list. Visitors still analyze up to six people at a time.
  7. Use Open members.js later to keep editing the same roster.

Turning off Browse later

When you no longer need to add charts from files, open this HTML file in a text editor, find the line var ENABLE_BROWSE = true; near the top of the script, change true to false, and save. Opening and saving members.js will still work; only Browse and drag-and-drop for chart files are hidden.
